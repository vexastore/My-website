# Task: Mobile Homepage Custom Category Dropdown & Scroll Preservation

## Summary
Replaced the native HTML `<select>` category dropdown on the mobile storefront homepage with a custom-styled, accessible dark glassmorphism dropdown matching the Vexa Toys luxury brand identity. Fixed an issue where selecting any category caused mobile browsers to jump back to the top of the homepage (hero banner) instead of showing the filtered catalog products.

## Why
1. On mobile devices (iOS Safari, Android Chrome), tapping the category dropdown displayed the native browser picker wheel / dialog. This contrasted sharply with the site's dark neon aesthetic and, due to a font-size < 16px, triggered iOS Safari form zoom.
2. In `ShopContext.tsx`, `setActiveCategory` was implemented by `navigateToCategoryFn`, which unconditionally called `window.scrollTo(0, 0)`. Furthermore, closing the native form picker in mobile Safari caused viewport repositioning. Together, this caused selecting any category to throw the user back up to the hero section instead of displaying the filtered products.

## How
1. **Custom Dropdown Component (`ProductList.tsx`)**:
   - Replaced `<select id="catalog-category">` with an accessible combobox trigger button and listbox popover (`role="combobox"`, `role="listbox"`, `role="option"`).
   - Styled with dark glassmorphism (`bg-[#121212]`, `border-white/15`, hover/active `#ff2d78`), custom rotating chevron, smooth opening animation, and selected indicator checkmarks.
   - Added `mousedown`, `touchstart`, and `Escape` listeners for click-outside and touch dismissal.
2. **Scroll Preservation & Direct Catalog Alignment**:
   - In `src/context/ShopContext.tsx`, updated `navigateToCategoryFn` so that `window.scrollTo(0, 0)` is only called when switching from another view (e.g., from product details or checkout). When already on `'shop'`, it preserves viewport scroll.
   - Added `scroll-mt-24 sm:scroll-mt-28` to `id="products-grid"` so scrolling to products positions cleanly below the sticky header.
   - Updated category selection in both the dropdown and filter drawer to trigger `scrollToProducts()`, bringing the filtered products grid smoothly into view.
3. **Automated Verification**:
   - Created `tests/category-dropdown.test.mjs` verifying the removal of `<select>`, presence of custom combobox attributes, `scroll-mt` definition, and `ShopContext` scroll preservation.
   - Verified clean production build (`next build`) and test suite pass (47/47 tests).
