# Worklog Entry 3 — 21 September 2026: Google Search Console Merchant Listings "Missing field 'validFrom' (in 'offers')" Remediation

## Summary
Resolved Google Search Console Merchant listings warning `Missing field 'validFrom' (in 'offers')` affecting 26 product items. Added `validFrom` and `itemCondition` to the Schema.org `Offer` generator in `lib/productSchema.ts`, ensuring deterministic ISO 8601 `YYYY-MM-DD` date generation from product `updatedAt` timestamps with fallback to the start of the current year. Updated the test suite with automated tests verifying all 26 reported URLs, verified zero TypeScript or linter errors, and confirmed valid JSON-LD in the Next.js production build and live server responses.

## Why
Google Search Console flagged a Merchant listings warning across 26 product URLs: `Missing field 'validFrom' (in 'offers')`. While marked non-critical, missing `validFrom` prevents Google from presenting enhanced Merchant listing rich features and price freshness badges. Providing `validFrom` along with `priceValidUntil` and `itemCondition` satisfies Google Merchant Center and structured data criteria for commercial listings.

## How
1. In `lib/productSchema.ts`, implemented `getOfferValidFrom(product: { updatedAt?: string }): string`:
   - Parses `product.updatedAt` if present and valid.
   - Ensures the timestamp is not in the future (capped to current date).
   - Formats the date as an ISO 8601 `YYYY-MM-DD` string.
   - Falls back to the start of the current year (`${year}-01-01`) for products without timestamps.
2. Updated the `offers` object in `generateProductJsonLd`:
   - Added `validFrom: getOfferValidFrom(product)`.
   - Added `itemCondition: 'https://schema.org/NewCondition'` to clarify all products are new.
3. Updated `tests/product-schema.test.mjs`:
   - Added unit test for `getOfferValidFrom` covering valid timestamps, missing timestamps, and future dates.
   - Added test covering all 26 URLs reported by Google Search Console, asserting that `offers.validFrom` is present, matches `YYYY-MM-DD`, and is $\le$ `priceValidUntil`.
4. Documented changes in `README.md`, `CHANGELOG.md`, `docs/features.md`, and `docs/Testing.md`.
